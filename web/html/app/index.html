Kiến Trúc Tương Tác CSDL SQL Server 2022

Ứng dụng này kết nối trực tiếp với Microsoft SQL Server 2022 Developer (container relational-database-server) thông qua Flask RESTful API và ODBC Driver 18. Dữ liệu bảng studentdb.dbo.students được lưu trữ lâu dài trên Docker named volume mycloud_mssql-data.

Thêm Sinh Viên Mới

Dữ liệu sẽ được ghi trực tiếp vào cơ sở dữ liệu studentdb trên SQL Server 2022 thông qua endpoint POST /api/students-db. Nếu chọn ảnh thẻ, ảnh sẽ được tự động lưu vào bucket MinIO profile-pics.
1-10 ký tự chữ/số/gạch nối, không trùng lặp.

Xác Thực Tập Trung Keycloak SSO (OIDC / OAuth 2.0)

Hệ thống sử dụng luồng chuẩn bảo mật Authorization Code Grant kết hợp PKCE S256 (Proof Key for Code Exchange) cho ứng dụng Single Page Application. Frontend tự sinh mã bảo mật, không nhúng client secret và chỉ coi token hợp lệ sau khi backend xác minh qua JWKS.

Trạng thái đăng nhập: Chưa đăng nhập
Đang tải cấu hình từ GET /api/auth/config...

Kiểm Tra Endpoint Bảo Vệ (GET /api/secure)

Gửi HTTP request kèm header Authorization: Bearer <access_token>. Backend sẽ kiểm tra chữ ký RS256 và issuer thực tế với Keycloak.

Tài Liệu Hợp Đồng API & Bảng Thử Nghiệm

Danh sách các endpoint được định nghĩa trong docs/api-contract.md. Bạn có thể nhấn Chạy thử đối với các endpoint an toàn (GET) để kiểm tra phản hồi trực tiếp từ hệ sinh thái MyMiniCloud.

GET /api/hello Sẵn sàng 
Bấm "Chạy thử (Run)" trên bảng bên dưới để xem dữ liệu phản hồi.
Method Endpoint URL Mô tả chức năng Thao tác an toàn
GET /api/hello Kiểm tra Application Backend Server hoạt động
GET /api/student Lấy 5 mẫu JSON tĩnh từ file students.json theo đề bài
GET /api/students-db Lấy danh sách sinh viên từ cơ sở dữ liệu SQL Server
GET /api/health Healthcheck ứng dụng và kết nối SQL Server
GET /api/status Trạng thái probe tổng thể 9 nhóm dịch vụ
GET /api/files?bucket=documents Liệt kê tệp tin hồ sơ PDF trên MinIO S3
GET /api/auth/config Lấy thông tin cấu hình OIDC từ Keycloak
POST /api/students-db Thêm sinh viên mới (thực hiện qua tab Thêm sinh viên) Thực thi tại Form
PUT /api/students-db/{id} Cập nhật sinh viên (thực hiện qua nút Sửa) Thực thi tại Modal Sửa
DELETE /api/students-db/{id} Xóa sinh viên (thực hiện qua nút Xóa) Thực thi có xác nhận
