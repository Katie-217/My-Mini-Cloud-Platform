Thêm Sinh Viên Mới

Dữ liệu được lưu trực tiếp vào database studentdb trên SQL Server 2022 qua endpoint POST /api/students-db. Ảnh đại diện tải lên MinIO S3 bucket profile-pics.
1-10 ký tự chữ/số/gạch nối.
Tối đa 100 ký tự.
Định dạng YYYY-MM-DD, không ở tương lai.
Từ 0.00 đến 4.00.
PNG hoặc JPEG, tối đa 10 MiB. Tải vào bucket private profile-pics.
