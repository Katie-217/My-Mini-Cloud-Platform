9 Nhóm Dịch Vụ Hạ Tầng

Chi tiết kỹ thuật, công nghệ và cơ chế kiểm thử thực tế của từng dịch vụ

Nhóm 01 Chưa probe

Web Frontend Server

Nginx 1.28-alpine cloud-net

Triển khai 2 replicas (web1, web2) phục vụ cùng nội dung Portal và Static Blog. Hỗ trợ kiểm thử cân bằng tải Round Robin từ Reverse Proxy.

Container: web-frontend-server1/2
Nhóm 02 Chưa probe

Application Backend Server

Python 3.12 / Flask cloud-net

Microservice phụ trách toàn bộ REST API: quản lý sinh viên SQL Server, upload/download tệp S3 MinIO, xác minh JWT token qua Keycloak JWKS endpoint.

Container: application-backend-server
Nhóm 03 Chưa probe

Relational Database Server

SQL Server 2022 Dev cloud-net

Cơ sở dữ liệu studentdb chứa bảng dbo.students. Dữ liệu được lưu trữ lâu dài bằng named volume mycloud_mssql-data.

Container: relational-database-server
Nhóm 04 Chưa probe

Authentication Server

Keycloak 26.1.4 cloud-net

Máy chủ danh tính tập trung OIDC. Quản lý Realm đồ án, client flask-app, luồng đăng nhập Authorization Code kết hợp PKCE chuẩn S256.

Container: authentication-identity-server
Nhóm 05 Chưa probe

Object Storage Server

MinIO S3 cloud-net

Lưu trữ tệp phi cấu trúc với 2 private buckets: profile-pics (ảnh thẻ sinh viên) và documents (hồ sơ PDF). Quản lý qua Backend proxy.

Container: object-storage-server
Nhóm 06 Chưa probe

Internal DNS Server

Bind9 9.18 cloud-net

Dịch vụ DNS có thẩm quyền (Authoritative DNS) quản lý zone cloud.local, phân giải IP tĩnh cho các dịch vụ app-backend, minio, keycloak.

Container: internal-dns-server (1053)
Nhóm 07 Chưa probe

Monitoring Prometheus

Prometheus / Exporters cloud-net

Thu thập số liệu đo lường định kỳ từ Node Exporter (CPU, RAM, Disk, Net của Docker Linux VM) và Blackbox Exporter (kiểm tra khả năng phản hồi HTTP của 2 Web Server).

Container: monitoring-prometheus-server
Nhóm 08 Chưa probe

Logging & Visualization

Grafana 11.6.0 cloud-net

Bảng điều khiển trực quan hóa thời gian thực. Tự động nạp dashboard giám sát với 3 đồ thị PromQL thực tế, bảo lưu cấu hình qua named volume.

Container: monitoring-grafana-dashboard
Nhóm 09 Chưa probe

API Gateway & Load Balancer

Nginx Reverse Proxy cloud-net

Điểm tiếp nhận lưu lượng duy nhất từ bên ngoài qua cổng 80. Điều phối request đến 2 Web Replicas theo thuật toán Round Robin, chuyển tiếp API và SSO Keycloak.

Container: api-gateway-proxy-server

Hệ Thống Giám Sát & Đo Lường

Số liệu metric được thu thập thực tế qua Prometheus và trực quan hóa trên Grafana

Ghi chú kỹ thuật: Giao diện web này không tự tạo số liệu CPU/RAM giả lập. Toàn bộ thông số hiệu năng được Prometheus thu thập từ Node Exporter của Docker Linux VM và hiển thị trực tiếp trên Grafana Dashboard.
node_cpu_seconds_total

Đo thời gian CPU hoạt động theo các chế độ (user, system, idle). Dùng để tính toán tỷ lệ tải CPU thực tế (%) của host.

node_memory_MemAvailable_bytes

Đo dung lượng bộ nhớ RAM khả dụng còn lại mà hệ thống có thể cấp phát cho các tiến trình mà không cần swap.

node_network_receive_bytes_total

Đo tổng lưu lượng byte mạng nhận được qua các giao diện mạng ảo (eth0) của Docker daemon.

Mở Grafana Dashboard (:3000) Xem Scrape Targets (:9090/targets)

Kịch Bản Demo 10 Bước

Quy trình kiểm thử và nghiệm thu toàn diện hệ thống MyMiniCloud

  1. 1

    Khởi động hệ thống Docker Compose

    Khởi chạy toàn bộ 9 nhóm dịch vụ trong project mycloud bằng lệnh docker compose up -d. Kiểm tra các container ở trạng thái Up và hoàn tất các init jobs.

  2. 2

    Kiểm tra Web Portal và Trạng thái Live

    Mở trình duyệt truy cập http://localhost/. Xác nhận thanh trạng thái đọc dữ liệu thực từ GET /api/status, kiểm tra số dịch vụ reachable và thông tin các nhóm.

  3. 3

    Khám phá Static Blog và Cân Bằng Tải

    Truy cập /blog/, đọc 3 bài viết chuyên đề. Gửi nhiều request và kiểm tra response header để thấy Nginx Reverse Proxy cân bằng tải Round Robin giữa web1 và web2.

  4. 4

    Kiểm tra Backend REST API & Student JSON

    Kiểm tra API cơ bản GET /api/hello và endpoint tĩnh GET /api/student (đọc 5 sinh viên mẫu từ file JSON theo yêu cầu đồ án).

  5. 5

    Thực hiện CRUD Sinh viên trên SQL Server 2022

    Vào trang Quản lý Sinh viên (/app/): Xem danh sách, thêm sinh viên mới, cập nhật thông tin và xóa. Dữ liệu được ghi trực tiếp vào SQL Server studentdb và bảo lưu qua named volume.

  6. 6

    Lưu trữ tệp phi cấu trúc trên MinIO S3

    Upload ảnh thẻ vào bucket profile-pics và tải tài liệu PDF vào bucket documents. Xác nhận file tải về thành công và kiểm tra trên MinIO Console (:9001).

  7. 7

    Đăng nhập tập trung OIDC PKCE với Keycloak

    Thực hiện luồng đăng nhập Authorization Code kèm mã hóa PKCE S256 với tài khoản demo. Gửi access token gọi endpoint bảo vệ GET /api/secure và nhận xác nhận từ backend.

  8. 8

    Xác minh phân giải tên miền Bind9 DNS

    Sử dụng công cụ dig truy vấn máy chủ Bind9 qua cổng 1053: dig @127.0.0.1 -p 1053 app-backend.cloud.local để kiểm tra phân giải bản ghi A trong zone nội bộ.

  9. 9

    Kiểm tra giám sát Prometheus Scrape Targets

    Truy cập http://localhost:9090/targets. Xác nhận target Node Exporter và HTTP Exporter (probe Nginx web replicas) đều ở trạng thái UP.

  10. 10

    Trực quan hóa tài nguyên trên Grafana Dashboard

    Mở Grafana tại http://localhost:3000, xem dashboard System Health với 3 biểu đồ dữ liệu thời gian thực: CPU Usage, Bộ nhớ RAM khả dụng và Lưu lượng mạng.
